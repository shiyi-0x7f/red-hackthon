# Phase 3 — 高级自适应

> V3 阶段（第 7-12 月）：棋类模块、全能挑战、认知特征完整建模、虚拟宠物、家长端、个性化学习路径。

---

## 一、阶段目标

> 从"教得好"升级为"全面理解学生"——通过多场景数据（棋类、挑战、深度对话）完善认知特征层，实现真正的个性化学习路径规划。

---

## 二、棋类模块（休息区）

### 2.1 定位

> 休息中的轻认知训练 + 认知行为数据采样，不是游戏产品。

### 2.2 支持的棋类

| 棋类 | 复杂度 | 认知观测点 |
|------|--------|-----------|
| 井字棋 | 极低 | 基础策略、反应 |
| 五子棋 | 低 | 局部 vs 全局、规划 |
| 象棋(残局) | 中 | 多步规划、风险控制 |
| 围棋(小棋盘) | 高 | 全局意识、长期规划 |

### 2.3 AI 复盘引导

棋局结束后 AI 引导复盘：
- 你为什么下这步？
- 当时你担心什么？
- 你有没有看到对方威胁？
- 现在回看还有别的走法吗？

### 2.4 数据回流

从棋类行为提取的特征 → 更新认知层：
- 风险走法比例 → risk_control
- 局部 vs 全局选择 → global_awareness
- 错误后恢复步数 → recovery_ability
- 连续决策质量一致性 → stability

### 2.5 控制措施
- 作为休息触发，有时长上限
- 结束后带一句复盘
- 不能太强游戏化

## 三、全能挑战

### 3.1 定位

> 轻量、非诊断性的认知与策略任务，用于采样学生的认知特征。

**统一命名"全能挑战"**，底层是教育型认知采样任务。

### 3.2 任务类型

| 任务 | 测量维度 |
|------|---------|
| 工作记忆游戏 | 记忆容量、信息保持 |
| 规则切换任务 | 认知灵活性 |
| 视觉模式识别 | 模式识别能力 |
| 多步规划任务 | 规划深度 |
| 不确定性决策 | 风险偏好 |
| 反应抑制任务 | 冲动控制 |

### 3.3 输出规范

不输出：IQ 分数、人格类型、焦虑指数

输出：
- 在规则切换类任务中表现较强
- 多步规划优于同龄平均
- 压力下速度快于准确性

## 四、认知特征层完善

### 4.1 完整字段

| 字段 | 数据源 |
|------|--------|
| global_awareness | 棋类 + 数学多步题 |
| risk_control | 棋类 + 决策任务 |
| stability | 跨会话表现一致性 |
| recovery_ability | 错误后恢复数据 |
| cognitive_flexibility | 全能挑战规则切换 |
| working_memory | 全能挑战 |
| planning_depth | 棋类 + 规划任务 |

### 4.2 认知→数学映射

| 认知特征 | 数学中的表现 | 教学干预 |
|---------|-------------|---------|
| 全局意识弱 | 只盯局部数字变形 | 先分类题型再选策略 |
| 风险控制弱 | 不验证条件就代入 | 强化动手前检查 |
| 规划深度浅 | 做无效步骤 | 增加"写出下一步目标" |
| 恢复能力弱 | 出错后乱做 | 插入暂停-复述-重规划 |

## 五、虚拟宠物（完整版）

### 5.1 核心原则

> 宠物不是情感对象，而是学习过程的可视化映射。

### 5.2 设计要点

- **外形**：抽象宠物（光团/几何生命体），非真实动物
- **成长绑定学习**：理解提升→形态变化，规划更好→更稳定
- **不索取情感**：不说"你怎么不陪我"
- **不依赖强化**：不来不会变差
- **不喂养**：无道具、无打卡养成

### 5.3 成长体系

```
学习积累 → 外观变化
能力提升 → 结构变化
掌握稳定 → 动作更流畅
```

## 六、家长端

### 6.1 功能

| 功能 | 说明 |
|------|------|
| 学习进度 | 知识掌握概览、近期变化 |
| 使用健康 | 学习时长、休息情况、超时次数 |
| 节奏建议 | 建议的学习频率和时长 |
| 周报/月报 | 自动生成的学习报告 |

### 6.2 隐私控制
- 家长不看原始对话内容
- 只看汇总数据和趋势
- 不暴露"标签化"的特征分数

## 七、个性化学习路径

### 7.1 路径规划

基于完整学生模型，自动生成周/月学习计划：

```typescript
interface LearningPath {
    weekly_goals: KnowledgeGoal[];
    daily_plan: DailyPlan[];
    review_schedule: ReviewItem[];
    difficulty_trajectory: number[];
    adjustment_triggers: AdjustmentRule[];
}
```

### 7.2 动态调整
- 掌握快 → 加速推进
- 遗忘风险高 → 插入复习
- 状态差 → 降低强度
- 兴趣转变 → 调整包装

## 八、决策引擎 V2

### 8.1 从规则到混合

- 保留硬规则层不变
- 策略层引入简单 ML（XGBoost/LightGBM）
- 基于历史干预效果数据训练
- 输入：学生画像 + 任务上下文
- 输出：策略选择概率

### 8.2 策略效果自动评估

```typescript
// 每次干预后自动评估
async function evaluateStrategy(intervention: Intervention, outcome: TaskResult) {
    const success = outcome.isCorrect && outcome.hintCount === 0;
    await updateStrategySuccess(intervention.strategy, success);
}
```
