### 2.3 硅基流动 (SiliconFlow) API

通过 AstrBot 的 Provider Manager 统一管理 LLM 调用：

| 模型 | 适用场景 | 说明 |
|------|---------|------|
| DeepSeek-V3 | 讲解/判题/复杂推理 | 数学能力强 |
| Qwen2.5-72B | 出题/问答 | 通用能力好 |
| GLM-4 | 对话/轻交互 | 中文对话流畅 |
| 其他模型 | 用户可自行配置 | AstrBot 管理面板可配 |

**关键特性**：
- AstrBot Provider Manager 统一管理多 LLM 接口
- 在 AstrBot 管理面板中配置 API Key 和模型选择
- 支持流式输出 (SSE)
- 按 token 计费，成本可控

### 2.4 数据库

| 类型 | 技术 | 说明 |
|------|------|------|
| **主库** | SQLite 3 (SQLModel) | AstrBot 统一数据库 |
| **向量检索** | FAISS | AstrBot 知识库模块 |
| **缓存** | Python dict / 内存 | 学生实时状态 |
| **文件存储** | 本地文件系统 | AstrBot data 目录 |

**为什么用 FAISS 而不是 LanceDB**：
- AstrBot 原生集成 FAISS，无额外依赖
- 符合"复用原生能力"原则
- 单用户数据量小，FAISS 完全够用

## 四、前后端通信方式

### REST API（核心）

前端通过 HTTP 调用后端 API：

```typescript
// 前端调用（Vue composable）
import axios from 'axios'

// 获取学生画像
const { data } = await axios.get(`/api/student/${studentId}/profile`)

// 提交答案
const result = await axios.post('/api/learning/answer', {
    session_id: sessionId,
    task_id: taskId,
    answer: studentAnswer,
    time_spent_sec: timeSpent
})
```

```python
# 后端路由（Quart）
from quart import Blueprint, jsonify, request

learning_bp = Blueprint('learning', __name__)

@learning_bp.route('/api/learning/answer', methods=['POST'])
async def submit_answer():
    data = await request.get_json()
    result = await question_service.judge_answer(
        session_id=data['session_id'],
        task_id=data['task_id'],
        answer=data['answer'],
        time_spent=data['time_spent_sec']
    )
    return jsonify(result)
```

### SSE 流式通信（LLM 流式输出）

使用 Server-Sent Events 实现流式推送：

```python
# 后端：流式调用 LLM
from quart import Response

@learning_bp.route('/api/chat/stream', methods=['POST'])
async def stream_chat():
    data = await request.get_json()
    
    async def generate():
        async for chunk in llm_provider.stream_chat(data['messages']):
            yield f"data: {json.dumps({'content': chunk})}\n\n"
        yield "data: [DONE]\n\n"
    
    return Response(generate(), mimetype='text/event-stream')
```

```typescript
// 前端：监听 SSE 流
const eventSource = new EventSource('/api/chat/stream')
eventSource.onmessage = (event) => {
    if (event.data === '[DONE]') {
        eventSource.close()
        return
    }
    const chunk = JSON.parse(event.data)
    appendToOutput(chunk.content)
}
```

## 七、LLM 调用架构

### 7.1 通过 AstrBot Provider 调用

```python
# 直接复用 AstrBot 的 Provider Manager
class QuestionService:
    def __init__(self, core_lifecycle):
        self.core = core_lifecycle
    
    async def judge_answer(self, question, student_answer, grade):
        """调用 AstrBot LLM Provider 判题"""
        prompt = JUDGE_PROMPT.format(
            question=question.content,
            answer=question.answer,
            student_answer=student_answer,
            grade=grade
        )
        provider = self.core.provider_manager.get_default_provider()
        result = await provider.text_chat(prompt=prompt)
        return parse_json_result(result)
```

> 不需要自己写 HTTP 客户端，AstrBot Provider Manager 已封装好多模型切换、流式输出、错误重试等能力。

### 7.2 成本控制

| 场景 | 策略 |
|------|------|
| 讲解复杂概念 | 全量模型（DeepSeek-V3） |
| 判题错因分析 | 全量模型 |
| 简单问答 | 轻量模型（GLM-4） |
| 出题(模板化) | 规则优先，不够才调 LLM |
| 对话调节 | 轻量模型，短对话 |
| 缓存 | AstrBot 知识库缓存常见讲解 |
