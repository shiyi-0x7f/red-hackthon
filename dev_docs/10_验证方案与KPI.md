# 验证方案与 KPI

> 本文档定义各阶段的验收标准、核心 KPI、A/B 测试方案和风险控制措施。

---

## 一、MVP 验证方案

### 1.1 核心假设

> **长期学生模型 + 教学决策引擎，能否显著优于普通 AI Tutor？**

### 1.2 A/B 测试设计

| 项目 | 对照组 A | 实验组 B |
|------|---------|---------|
| 系统 | 普通 AI 出题+判题+讲解 | 完整系统（学生模型+决策引擎+节奏控制） |
| 个性化 | 仅难度调整 | 全面个性化 |
| 记忆 | 会话级 | 长期学生模型 |
| 状态 | 不感知 | 实时感知+节奏调节 |

### 1.3 测试指标

| 维度 | 指标 | 预期提升 |
|------|------|---------|
| **学习效果** | 正确率提升速度 | +15-25% |
| **学习效果** | 知识掌握稳定性 | +20% |
| **学习效果** | 遗忘率 | -20% |
| **学习效率** | 单位时间掌握知识量 | +20% |
| **行为改善** | 重复错误减少率 | -30% |
| **行为改善** | 提示依赖度下降 | -20% |
| **留存** | 次日留存率 | +15% |
| **留存** | 学习中断率 | -25% |
| **健康** | 超时使用率 | < 10% |

### 1.4 测试样本
- 最少 30 名受试学生
- 分组平衡（年级、基础水平）
- 测试周期 ≥ 4 周

## 二、核心 KPI 体系

### 2.1 学习效果 KPI

| 指标 | 计算方式 | 目标 |
|------|---------|------|
| 掌握率提升 | 知识点 mastery > 0.7 的比例变化 | 月增 10% |
| 错误重复率 | 同类错误再次出现比例 | < 15% |
| 遗忘率 | 复习时掌握度低于上次的比例 | < 20% |
| 迁移成功率 | 在新题型上应用已学知识 | > 60% |

### 2.2 学习效率 KPI

| 指标 | 计算方式 | 目标 |
|------|---------|------|
| 知识点掌握速度 | mastery 从 0.3→0.7 所需天数 | 行业对比 |
| 提示依赖趋势 | 月度 hint_dependency 变化 | 持续下降 |
| 独立完成率 | 无提示正确完成的比例 | 月增 5% |

### 2.3 行为改善 KPI

| 指标 | 计算方式 | 目标 |
|------|---------|------|
| 规划性提升 | planning_score 月度趋势 | 正向 |
| 冲动度下降 | impulsivity 月度趋势 | 负向 |
| 复盘质量 | 复盘时修正的准确度 | 提升 |

### 2.4 使用健康 KPI

| 指标 | 计算方式 | 目标 |
|------|---------|------|
| 超时率 | 超过年龄上限的会话比例 | < 10% |
| 中断率 | 非正常结束的会话比例 | < 15% |
| 聊天超量率 | 对话超日上限的天数 | < 5% |
| 对话收束成功率 | 对话在设定时间内结束 | > 90% |

## 三、各阶段验收清单

### MVP（1-3 月）

**基础功能**：
- [ ] 知识图谱正确展示层级和依赖
- [ ] 题库按条件筛选出题，AI 出题格式正确
- [ ] 判题错因分类准确率 > 80%
- [ ] 提示分层返回
- [ ] 问答符合"学习搭子"风格
- [ ] 数学公式正确渲染

**学生模型**：
- [ ] mastery_score 随答题正确/错误合理变化
- [ ] 遗忘风险随时间合理上升
- [ ] 行为特征（冲动/依赖）与实际行为一致
- [ ] 状态实时更新延迟 < 100ms

**决策引擎**：
- [ ] 疲劳高时不推新题
- [ ] 连续错误后建议休息
- [ ] 遗忘风险高的优先复习
- [ ] 决策含可读 reasoning

**节奏控制**：
- [ ] 时间到达前有预警
- [ ] 收束包含总结+选择
- [ ] 超时进入降级模式
- [ ] 不突然切断

**轻量对话**：
- [ ] 对话 3-8 分钟自动收束
- [ ] 每日上限生效
- [ ] 冷却机制生效
- [ ] 提取信息更新模型

**安全**：
- [ ] 所有输出无禁用词
- [ ] 无人格判断
- [ ] 无情感绑定表达
- [ ] 敏感内容能触发升级

---

### V2（4-6 月）

- [ ] 前端事件采集覆盖率 > 90%
- [ ] 行为特征计算与实际行为匹配
- [ ] 长时记忆能正确召回相关内容
- [ ] 阅读材料自动切章节+生成问题
- [ ] 语音抽背识别准确率 > 85%
- [ ] Live2D 状态切换流畅
- [ ] 教师端报告含可操作建议

### V3（7-12 月）

- [ ] 棋类数据正确映射到认知特征
- [ ] 全能挑战输出行为描述（非分数）
- [ ] 宠物成长与学习进步关联
- [ ] 家长端不暴露原始对话
- [ ] 学习路径动态调整生效
- [ ] 决策引擎 V2 优于 V1（可量化）

## 四、风险控制

### 4.1 风险矩阵

| 风险 | 概率 | 影响 | 控制措施 |
|------|------|------|---------|
| 隐私/未成年人 | 中 | 🔴 极高 | 数据分级、家长授权、最小采集、加密 |
| 过度画像/标签 | 高 | 🔴 高 | 非诊断原则、置信度、证据链 |
| 产品失焦 | 中 | 🟡 中 | 一切围绕学习、辅助服务主决策 |
| 模型效果弱 | 中 | 🟡 中 | A/B 测试、先验证核心变量 |
| 数据噪声 | 高 | 🟡 中 | 多源验证、时间平滑、置信度 |
| 情感依赖 | 中 | 🟡 中 | 时限、收束、反依赖设计 |
| LLM 成本 | 中 | 🟡 中 | 缓存、分级调用、轻量兜底 |
| LLM 幻觉 | 高 | 🟡 中 | 结构化输出、后处理校验 |

### 4.2 未成年人保护措施

- [ ] 数据加密存储
- [ ] 家长授权机制
- [ ] 最小数据采集
- [ ] 对话内容不向第三方传输
- [ ] 敏感内容即时升级
- [ ] 使用时长严格控制
- [ ] 定期数据清理策略

```
W7-8:   学生模型                          → 画像可查看
W9-10:  决策引擎 + 学习主引擎              → 智能推荐
W11-12: 节奏控制 + 对话 + 集成测试         → MVP 完成

M4-6:   V2 增强观测                       → 过程分析
M7-12:  V3 高级自适应                     → 完整系统
```
